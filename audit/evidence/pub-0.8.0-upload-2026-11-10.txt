Propagation observation
  Immediately after an upload the public JSON API reported the new version while
  the pub client's version listing for that package still ended at 0.7.0 (the
  archive and `/api/packages/<name>/versions/<version>` endpoints were already
  200). Fresh `PUB_CACHE` directories did not help, so this was pub.dev edge
  indexing, not a local cache. It cleared package by package within minutes;
  `dart pub cache add <name> --version 0.8.0` succeeded for all seven in the
  first round after the last index caught up. This is why "verify on pub.dev"
  was done against the client-visible listing, not only the `latest` field.
