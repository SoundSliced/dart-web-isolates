Prototype (disposable copy, commit d939ba8351 in that copy)
-----------------------------------------------------------
One source change in flutter_tools/lib/src/build_system/targets/web.dart:
Dart2WebTarget.dependencies gains BuildHooks(platform: HookPlatform.web).
Test additions:
- web_test.dart: two assertions that Dart2JSTarget and Dart2WasmTarget each
  depend on exactly one BuildHooks with HookPlatform.web.
- test/integration.shard/build_hooks_generate_dart_web_test.dart: a fresh app
  whose hook writes lib/generated.g.dart (imported by main.dart) builds on the
  first `flutter build web --release --no-pub`.

Results on the patched copy
---------------------------
- flutter_tools web target suite: 623 tests pass.
- Integration test: passes (0:26).
- Verbose ordering: "build_hooks: Complete" precedes "dart2js: Starting due to {}".
- First-build matrix (fresh fixture per row, ordinary command):
    --release, dwi js    -> exit 0; main.dart.js, dwi/worker.dart.js
    --release, dwi wasm  -> exit 0; main.dart.js, dwi/worker.boot.mjs,
                            dwi/gen-<hash>/{worker.mjs,worker.wasm}
    --wasm, dwi js       -> exit 0; main.dart.{js,wasm}, dwi/worker.dart.js
    --wasm, dwi wasm     -> exit 0; main.dart.{js,wasm}, Wasm worker bundle
    --debug, dwi js      -> exit 0; main.dart.js, dwi/worker.dart.js
    --profile, dwi js    -> exit 0; main.dart.js, dwi/worker.dart.js
    flutter run -d chrome -> first command reaches key commands
- Chrome runtime:
    release JS at "/"            -> result 168; 200 /dwi/worker.dart.js
    wasm host + wasm worker "/"  -> result 168; 200 worker.boot.mjs,
                                    worker.mjs, worker.wasm
    same build at "/sub/app/"    -> result 168; all assets and worker 200
  (Wasm worker requires the app itself to configure DwiWorkerBackend.wasm and
  DwiConfig.defaultWasmWorkerScript; dwi.yaml alone selects what the builder
  emits, not what the app loads.)

Regression cases
----------------
- Throwing hook: exit 1, "Target build_hooks failed", "Bad state: hook boom",
  no dart2js start, no build/web.
- dwi.yaml lifecycle: absent -> JS worker; created target: wasm -> Wasm worker
  bundle; deleted -> JS worker recompiled. Old Wasm artefacts are retained.
- Link hooks/final packaging: worker asset present in every matrix row.

Not measured
------------
- A dependency hook producing assets but no Dart source.
- Multiple dependencies with web hooks.
- Safari, Firefox, Edge runtime.
- Any build on 3.47.9 (source inspection only).
